## What is this project?
This software will encode an LED Matrix board from Hanover Displays, commonly found in buses. In this instance, I'm going to turn it into a clock/bus tracker, though this software will include more than my original plan since I want it to let others display their own info on similar signs.
[Image] 

## What do I need for this project
- You will need one Hanover Display matrix board
- A 24V electrical supply (I recommend a wall plug)
- An Arduio
- A MAX485 TTL-to-RS485 breakout module
- Cable (will specify more when I finish the project)

## What you need on your system
pywebview 5.0
